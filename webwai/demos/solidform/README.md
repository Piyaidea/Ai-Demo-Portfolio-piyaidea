# SOLIDFORM — WEBWAI Demo 03

เว็บไซต์ช่างรับเหมา / งานก่อสร้างแบบ HTML, CSS, JavaScript ไม่ต้องติดตั้งแพ็กเกจหรือ build

## ไฟล์ที่แก้ได้
- `index.html`: หน้าแรก ข้อความหลัก และบริการย่อ
- `services.html`: รายละเอียดบริการและขั้นตอนงาน
- `projects.html`: รายการโครงการและหมวดตัวกรอง
- `project.html`: โครงหน้ารายละเอียดโครงการ
- `assets/project.js`: ข้อมูลโครงการตาม URL `?id=build`, `reno`, `shop`
- `contact.html`: แบบฟอร์มเตรียมโจทย์
- `assets/style.css`: สี ฟอนต์ ระยะห่าง และมือถือ
- `assets/main.js`: เมนู ตัวกรอง สร้าง / คัดลอก / ดาวน์โหลดข้อความ
- `assets/house.jpg`: ภาพบ้านจาก Unsplash photo-1600585154340-be6161a56a0c

## ใช้งานแยกเป็นเว็บ
คัดลอกทั้งโฟลเดอร์นี้ไปไว้ในโฮสติ้ง แล้วเปิด index.html ไม่ต้องใช้ CSS หรือ JS ของ WEBWAI
ลิงก์กลับ WEBWAI ใช้ `../../` ถ้าย้ายไปเป็นเว็บเดี่ยว ให้เปลี่ยนเป็น URL ของ WEBWAI หรือเอาลิงก์กลับออก

ข้อมูลและโครงการทั้งหมดสมมติ ไม่มี backend และแบบฟอร์มไม่ส่งข้อมูลจริง

## แก้ใน GitHub
แก้ไฟล์บน branch `webwai-main` แล้ว commit สำหรับเก็บต้นฉบับ
การเผยแพร่ GitHub Pages ใช้ branch `webwai-pages` ให้คัดลอกเฉพาะไฟล์ที่เปลี่ยนไปยัง path เดียวกันบน branch นี้ด้วย หรือให้ Codex ช่วยเผยแพร่
