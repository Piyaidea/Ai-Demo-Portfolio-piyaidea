# NORTHLINE — WEBWAI Demo 02

เว็บบริษัทบริการ 4 หน้า HTML / CSS / JavaScript

- `index.html`: หน้าแรก
- `services.html`: บริการ
- `about.html`: เกี่ยวกับบริษัท
- `contact.html`: แบบฟอร์มเตรียมรายละเอียด
- `assets/style.css`: สี ฟอนต์ และ responsive
- `assets/main.js`: เมนูมือถือและสร้าง / คัดลอกข้อความ
- `assets/office.jpg`: ภาพจาก Unsplash photo-1497366754035-f200968a6e72

คัดลอกทั้งโฟลเดอร์ไปโฮสติ้งเป็นเว็บเดี่ยวได้ ไม่มีไฟล์ดีไซน์ที่พึ่ง WEBWAI
ลิงก์กลับ WEBWAI ใช้ ../../ หากย้ายเป็นเว็บเดี่ยว ให้เปลี่ยนเป็น URL จริงหรือเอาลิงก์กลับออก
ข้อมูลสมมติ แบบฟอร์มไม่มี backend ไม่ส่งหรือบันทึกข้อมูลจริง
แก้ต้นฉบับที่ branch webwai-main และเผยแพร่ไฟล์ที่แก้บน branch webwai-pages ใน path เดียวกัน
