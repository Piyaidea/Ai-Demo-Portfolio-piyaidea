# LUMERA — WEBWAI Demo 04

เว็บตัวอย่างคลินิก / ความงาม 5 หน้า แบบ HTML, CSS, JavaScript ไม่ต้องติดตั้งแพ็กเกจหรือ build

## จุดแก้ไข
- `index.html`: หน้าแรก แบรนด์ ข้อความหลัก FAQ และบริการย่อ
- `services.html`: หมวดบริการและตัวกรอง
- `service.html`: โครงหน้ารายละเอียดบริการ
- `assets/service.js`: ข้อมูลบริการตาม query `?id=consult`, `care`, `plan`
- `about.html`: แนวคิดคลินิก
- `contact.html`: แบบฟอร์มเตรียมคำถาม
- `assets/style.css`: สี ฟอนต์ ระยะห่าง และ responsive
- `assets/main.js`: เมนู ตัวกรอง สร้าง / คัดลอก / ดาวน์โหลดข้อความ
- `assets/skin-care.jpg`: ภาพประกอบจาก Unsplash photo-1570172619644-dfd03ed5d881

## ใช้เป็นเว็บไซต์แยก
คัดลอกทั้งโฟลเดอร์ไปไว้ในโฮสติ้งแล้วเปิด index.html ไม่มี CSS / JS ที่พึ่ง WEBWAI
ลิงก์กลับ WEBWAI ใช้ ../../ หากย้ายเป็นเว็บเดี่ยว ให้เปลี่ยนเป็น URL ของ WEBWAI หรือเอาลิงก์กลับออก

## ข้อมูลและแบบฟอร์ม
คลินิกและบริการสมมติ ไม่มี backend หรือระบบจอง แบบฟอร์มสร้างข้อความใน Browser เท่านั้น ไม่ส่งและไม่บันทึกข้อมูลบนเซิร์ฟเวอร์
ก่อนใช้จริง ให้ใส่ข้อมูลแบรนด์ บริการ บุคลากร และราคาที่เจ้าของคลินิกยืนยันแล้ว ภาพในเดโมไม่ใช่คลินิกหรือผู้รับบริการจริง
